# Skills Matrix

## Critical
| Skill | Application |
|---|---|
| Solidity | Payroll contracts and access control |
| Avalanche L1 / EVM | Network and transaction integration |
| Avalanche eERC SDK | Encrypted transfers, balances, proof workflow |
| Cryptography fundamentals | Correct handling of encrypted values and proofs |
| Smart-contract security | Authorization, replay, invariants |
| Foundry | Compile, deploy, unit/fuzz/invariant tests |
| TypeScript | Type-safe frontend/backend |
| React / Next.js | User interface |
| Wallet integration | Signing, network, account lifecycle |
| Privacy engineering | Metadata, logs, storage, disclosure review |

## Important
| Skill | Application |
|---|---|
| Viem / Wagmi or compatible tooling | EVM interaction |
| API design | Backend endpoints if required |
| PostgreSQL / Supabase | Minimal metadata persistence |
| Blockchain event indexing | Reconciliation/history |
| Threat modeling | Identify attack paths |
| E2E testing | Complete workflow |
| CI/CD | Repeatable validation |
| UI/UX and accessibility | Trustworthy user experience |
| Observability | Privacy-safe diagnostics |

## Optional
CSV import, scheduled payroll, multi-token support, advanced analytics, enterprise integrations, multi-chain expansion.

## AI-assisted workflow skills
Context engineering, task decomposition, source-grounded code generation, code review, test generation, debugging, hallucination prevention, ADR maintenance.

## Human review required
Cryptographic design, auditor semantics, contract authorization, key management, privacy claims, production deployment, and security sign-off.
