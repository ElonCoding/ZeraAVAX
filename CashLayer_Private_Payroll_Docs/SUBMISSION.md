# Hackathon Submission Draft

## Working title
Private Payroll on CashLayer (final name TBD)

## Problem
Public blockchain transactions can expose sensitive salary amounts and balances. Avalanche has an audited eERC standard and SDK, but application-layer demonstrations of realistic confidential financial workflows are limited.

## Solution
A confidential payroll application that enables employers to create payroll batches, employees to receive encrypted token payments, salary amounts/balances to remain confidential, and authorized auditors to verify compliance. On-chain execution remains verifiable.

## USP
Private payroll with encrypted amounts and controlled auditor access.

## Ecosystem impact
A concrete eERC adoption demonstration and developer reference implementation for building confidential financial applications.

## Technical claims
Only include claims proven in deployed demo and tests. Clearly state network, SDK, contracts, and limitations.
