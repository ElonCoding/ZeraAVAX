# Contributing

## Workflow
1. Read `AGENTS.md`, relevant spec, and current `TASKS.md`.
2. Create a focused branch.
3. Implement one bounded task.
4. Add/update tests.
5. Run formatting, lint, typecheck, and tests.
6. Update docs/ADR when decisions change.
7. Open PR with evidence and limitations.

## Commit style
Conventional commits recommended: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`.

## PR checklist
- [ ] Requirements satisfied
- [ ] Tests added/updated
- [ ] No secrets or confidential data in code/logs
- [ ] Source-verified protocol/API usage
- [ ] Privacy impact considered
- [ ] Documentation updated
- [ ] Limitations stated
