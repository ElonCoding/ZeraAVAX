# Use Cases

## UC-01 Payroll batch
Employer creates, validates, reviews, and submits a batch; app tracks execution and evidence.

## UC-02 Employee payment verification
Employee connects wallet and retrieves their own payment/balance using official SDK.

## UC-03 Auditor verification
Authorized auditor follows protocol-supported access and verifies permitted payroll information.

## UC-04 Public on-chain verification
Observer checks transaction receipt/explorer while protected amounts remain unavailable.

## UC-05 Failure recovery
Operator reconciles pending/unknown state and avoids duplicate payment before any retry.
